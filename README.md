# CodeLens AI

Windows 桌面代码解析悬浮助手。复制代码或选择屏幕区域，使用你自己的 OpenAI 或 DeepSeek API 密钥生成中文解释。项目目前是首版原型。

## 运行

需要 Windows 10/11、Node.js 22 或更新版本，以及可用的 OpenAI 或 DeepSeek API 密钥。

```powershell
npm install
npm run typecheck
npm test
npm start
```

在右上角“设置”中选择服务商并输入对应的 API 密钥。OpenAI 默认模型为 `gpt-4.1-mini`；DeepSeek 默认模型为 `deepseek-flash`。两家的密钥和模型分别保存，切换服务商不会覆盖另一家的配置。截图识别需要所选模型支持图片输入。模型能力和 API 费用由服务商及你的账户决定。

## 使用

- `Ctrl+Alt+E`：唤出主窗口，并读取当前剪贴板的文字代码。
- `Ctrl+Alt+S`：选择当前鼠标所在显示器上的屏幕区域；按 Esc 取消。
- 也可以在窗口中粘贴代码，粘贴或拖入 PNG/JPEG/WebP 图片。
- 图片先转写成可编辑代码。核对转写结果后，再点击“开始解析”。
- 选择初学者或深入模式；点击解释卡片或代码行查看对应行段；解析后可继续提问。
- 点击“历史记录”可搜索、恢复或删除以前的代码解析；清空全部需要再次确认。历史包含后续追问。
- 右上角“收起”将主窗口变成贴边悬浮按钮。关闭按钮会退出程序。

复制和截图得到的行号从当前片段第 1 行开始，不代表编辑器中的原文件行号。模型可能漏掉行段或误解代码，请核对结果。截图中的不清晰部分会显示转写提示，但无法保证识别完整。

历史记录从 0.3.0 版起自动保存成功解析的结果。旧版没有保存的会话无法自动补入历史，升级前仍在旧窗口显示的内容请先自行保留。

## 构建安装包

```powershell
npm run dist:win
```

0.3.0 安装包输出到 `release/0.3.0/`。当前安装包未签名，Windows 可能显示发行者警告。

## 隐私与技术边界

API 密钥由 Electron `safeStorage` 使用 Windows 用户加密机制分别保存于本机。成功解析的代码、中文解释和追问也使用 `safeStorage` 加密，保存在应用的本机用户数据目录中；可在“历史记录”中删除。截图原图不会保存到历史。代码和截图只在你主动请求转写、解析或提问时发往当前选定的 OpenAI 或 DeepSeek API；程序不自动监控屏幕或修改编辑器文件。运行时需要网络连接。旧版本保存的 OpenAI 密钥和模型沿用原路径。

Electron 主进程管理窗口、全局快捷键、屏幕捕获、密钥与网络请求。渲染进程启用沙箱和上下文隔离，仅通过限定的 preload API 调用这些能力。

## 当前限制

- 截图选区仅覆盖鼠标所在的一块显示器；跨屏选区未实现。
- 不读取编辑器文件路径或原文件行号，也不与 VS Code 插件同步。
- 尚未提供离线模型、跨设备历史同步、自动更新或代码签名。
- 未使用真实 API 密钥做端到端请求；自动测试使用模拟响应。

调研与选型依据见 [GitHub 开源项目调研报告](../CodeLens%20AI_GitHub开源项目调研报告.md)，首版范围见 [SPEC.md](SPEC.md)。
